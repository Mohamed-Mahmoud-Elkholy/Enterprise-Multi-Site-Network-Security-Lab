# Enterprise Multi-Site Network & Security Infrastructure Lab

A hands-on enterprise networking and security lab built with GNS3, Cisco IOS, FortiGate, and Windows Server.

## Project Overview

This project simulates a multi-site enterprise infrastructure with a headquarters in Cairo and a branch in Alexandria. It focuses on network segmentation, dynamic routing, high availability, firewall security, and infrastructure services.

## Technologies

- GNS3
- Cisco IOS / IOU
- VLANs and Inter-VLAN Routing
- OSPF
- HSRP
- EtherChannel
- DHCP and DHCP Relay
- FortiGate Firewall
- Dual-WAN Routing and Failover
- Windows Server

## Network Design

- Cairo HQ and Alexandria branch
- Department-based VLAN segmentation
- Core switching and routing
- Firewall-based security boundaries
- Internal servers and DMZ
- Redundancy and failover design

## Repository Structure

- `Images/` — Network topology and lab screenshots
- `Documentation/` — Network design and IP addressing
- `configs/` — Sanitized device configurations
- `Verification/` — Routing, high-availability, and failover test evidence

## Verification Status

Features will be documented as verified only after testing them in the lab. Planned or incomplete functionality will be identified separately.

## Disclaimer

This is a virtual lab created for learning, testing, and demonstrating enterprise networking and security concepts. Public IP ranges used in the lab may be reserved documentation ranges rather than real Internet addresses.
