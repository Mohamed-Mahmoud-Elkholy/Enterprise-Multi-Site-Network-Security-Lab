# Network Device Configurations

This directory contains configuration files collected from the Enterprise Multi-Site Network Security Lab.

## Planned Configuration Files

- **Core Switches:** VLANs, SVIs, EtherChannel, HSRP, OSPF, and routing.
- **FortiGate Firewalls:** Interfaces, firewall policies, routing, HA, dual-WAN, security profiles, and VPN.
- **WAN Routers:** ISP connectivity and routing.
- **Alexandria Branch:** Core switching and OSPF configuration.

## Configuration Standards

- Use clear filenames that match the actual device hostnames.
- Include only configurations collected and verified from the lab.
- Remove passwords, private keys, tokens, and other sensitive information before publishing.
- Do not label a configuration as verified unless it has been tested.

## Status

Configuration files will be added after collection and review of the actual lab configurations.
